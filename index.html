macOS

Operativsystem
og filsystem

macOS er operativsystemet på Mac. Det styrer maskinen og lar oss bruke programmer og arbeide med filer.

Del 1

Systemprogrammer og snarveier

Systemprogrammer

Spotlight
Søker raskt etter programmer, filer og mapper på Macen.
Finder
Brukes til å finne, åpne, flytte og organisere filer og mapper.
Aktivitetsmonitor
Viser hvor mye CPU, minne, energi og nettverk programmer bruker.
Diskverktøy
Brukes til å formatere, administrere og kontrollere disker for feil.
Terminal
Lar deg styre Macen og arbeide med filer ved å skrive kommandoer.

Snarveier

Command + mellomrom⌘+Space
Åpner Spotlight, slik at du raskt kan søke på Macen.
Command + Tab⌘+Tab
Bytter mellom åpne programmer.
Command + Shift + 3⌘+Shift+3
Tar et skjermbilde av hele skjermen.
Command + Shift + 4⌘+Shift+4
Lar deg velge et område av skjermen og ta skjermbilde av det.
Command + Option + Escape⌘+Option+Esc
Åpner vinduet for å tvangsavslutte programmer som ikke svarer.

GiB, TiB, PiB og EiB er binære størrelsesenheter. 1 GiB = 1024 MiB. Teoretiske grenser kan være høyere enn det operativsystemet og lagringsmediet støtter.

Hva betyr journalling?

Journalling betyr at filsystemet registrerer endringer i en logg før de fullføres. Loggen gjør det lettere å gjenopprette et konsistent filsystem etter strømbrudd eller krasj.
